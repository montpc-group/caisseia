## Comment accepter

Ajoutez cette ligne à la description de votre première pull request, avec vos
nom et e-mail tels qu'ils figurent dans vos commits :

```
J'accepte le CLA MONTPC v1.0 (CLA.md) pour mes contributions à ce dépôt. — Prénom Nom <e-mail>
```

Avant la fusion, le mainteneur recopie cette acceptation dans le commit de
fusion (voir [CONTRIBUTING.md](./CONTRIBUTING.md)) : c'est cette trace qui
fait foi.

Pour une contribution faite pour le compte d'une entreprise, écrivez à
contact@montpc.com avant d'envoyer le code.
